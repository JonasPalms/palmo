## About

A low-friction space for trying out new ideas without the overhead of spinning up a fresh repo every time. Built with Astro and MDX so I can write interactive demos alongside explanations.

## Why

Every developer accumulates random experiments — CSS tricks, animation tests, API explorations. Most of these die in local folders or get lost in CodePen. Palmground gives them a permanent home with the added benefit of being shareable.

## Features

- **MDX-powered** — Write demos with prose and code side by side
- **Syntax highlighting** via Shiki — Looks good out of the box
- **Zero friction** — Add a new `.mdx` file, done

## What's In There

A growing collection of web experiments:

- CSS layout explorations
- Animation tests
- JavaScript utilities
- Whatever catches my interest
