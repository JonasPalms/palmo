## About

A low-friction space for trying out ideas without spinning up a fresh repo every time. Built with Astro and MDX so I can ship demos with a bit of context.

## Why

I kept losing small experiments in folders and old gists. Palmground gives them a simple, shareable home.

## Features

- **MDX-powered** - Prose and code side by side
- **Syntax highlighting** via Shiki
- **Zero friction** - Add a new `.mdx` file, done

## What's In There

A growing collection of small web experiments: layouts, animations, and little utilities.

Check out the [live site](https://jonaspalms.github.io/palmground/) to see what's cooking.
